# New HIMS

Production-grade, multi-tenant Hospital Information Management System.

## Architecture

- Web: Next.js + React + TypeScript + Tailwind CSS + shadcn/ui
- Backend: NestJS + TypeScript
- Mobile: React Native + Expo + TypeScript
- Data platform: self-hosted Supabase/PostgreSQL
- Jobs/cache: Redis + BullMQ

See `docs/` for the PRD, SRS, development blueprint, database schema, API contract, event catalogue, permission matrix, and audit.
